WH8 — window kind (dialog/popup) and tabbing identifier.

BEFORE THE WORK. Same probe, same pristine copy, same command as `WH1.before.txt`:

    cd /tmp/gpui-before
    timeout -k 5 25 gos run --main-thread tests/gui/wh_window_options.gos

    exit 124, no output on stdout or stderr.

Half of the row was already reachable: `kind=popup` and `kind=floating` were two
of the twelve keys the old `app.rs::window_options` read, and
`examples/25_window_positioning.gos` opens a popup with one. The other half was
not: `WindowOptions::tabbing_identifier: Option<String>`
(`gpui-0.2.2/src/platform.rs:1136`) had no token and no reader, and the macOS
backend reads it as the switch that turns automatic window tabbing on for the
whole application (`platform/mac/window.rs:595-600`).

Neither half has a *reader* on `Window`: gpui exposes no `Window::kind()` and no
`Window::tabbing_identifier()`. So the check is the same mirror WH1 and WH3 use —
what went into the `WindowOptions` the window was opened with.
