AFTER THE WORK. Command, in this tree:

    TIER_TIMEOUT=25 ./scripts/tiers tests/gui/w3_events.gos

Output, identical on all five tiers (`check` prints `check: ok (2 items typed)`;
each of the other four exits 0 with no stderr):

    OK W3 each window drained only its own events across 6 frames

What makes it pass: `gpui-binding/src/store.rs` holds one `VecDeque<String>` per
window behind `LazyLock<Mutex<HashMap<i64, VecDeque<String>>>>`, and
`push_event`/`take_events` resolve the window through `crate::window::current()`.
Every callback that raises an event outlives the frame that built it, so each
one re-enters through `window::with(win, ..)` — in `view.rs` for the button,
checkbox, input, slider and pointer handlers, in `app.rs` for the keystroke
observer, the menu action slots, the timer and the background task, and in
`editor.rs` for the editor's own `changed()`.
