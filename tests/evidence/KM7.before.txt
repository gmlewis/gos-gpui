**`-99.00,-99.00` is a sentinel and not a reading.** `<id>.dx` and `<id>.dy` do not exist at
HEAD, and the probe reads them through `gpui::state_float(.., -99.0)`, so a missing slot is
distinguishable from a slot holding zero — which is the whole point of the assertion above it,
since a delta of zero and no delta at all would otherwise read the same. The same shape is
used for the counts, which read `0`.

**The window-level move passes at HEAD and is asserted anyway.** It is not one of the three
kinds this row added — it came in with `DD4`'s `gpui::on_mouse_window` — and it is in the file
because the departure assertions after it are only worth reading if the listener that carries
the pointer's position is still working. A green line among red ones is what says the reds are
about the three kinds and not about the probe having fallen over.

The run tiers exit `0 — no verdict` rather than `124`: the program reached the end of its
frames and never printed a verdict, so nothing about it hung.
