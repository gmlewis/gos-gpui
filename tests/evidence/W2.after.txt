What makes it pass: `gpui-binding/src/store.rs` now holds one `Store` per window
behind `LazyLock<Mutex<HashMap<i64, Store>>>`, every accessor takes the window
(an `_in` twin taking it explicitly, the plain one taking `crate::window::
current()`), and `gpui-binding/src/app.rs` installs the window id around the
whole of `Root::render` so the callback, the element translation and the
requests all run as the window they belong to.

`outside_a_frame_there_is_no_window` is the other half of W1: window `0` is the
namespace a program with no window — `gos test` — reads and writes, and it is
not window 1.

cannot prove that the *current* window is resolved correctly while frames are
running. That is `tests/gui/w2_window_state.gos`:

Two windows open at once, both writing the same key on every frame; each reads
it back through the window it is in, and from frame 5 each also reads the
*other* window's namespace with `state_int_in`. Neither ever sees the other's
value.

No before-transcript for this half on its own: the probe's first call is
`gpui::state_int_in`, which does not exist at HEAD, so against the pristine tree
it fails the same way the headless test does — `GX0002`, unresolved symbol. The
behaviour it guards is the one `W2.before.txt` records.
