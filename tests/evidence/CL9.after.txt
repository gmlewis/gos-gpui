CL9 — a program-facing clipboard, read/write, text and image.

AFTER THE WORK. Command, in this tree:

    TIER_TIMEOUT=45 ./scripts/tiers.sh tests/gui/cl9_clipboard.gos

Output, identical on all five tiers (`check` prints `check: ok (1 items typed)`;
each of the other four exits 0 with no stderr):

    OK CL9 text written to the clipboard reads back with the right kind, and what was there is restored

What the probe does: it keeps whatever the clipboard holds, writes a distinctive
marker with `gpui::set_clipboard_text`, reads it back with `gpui::clipboard_text`
and checks the kind with `gpui::clipboard_kind`, and then **puts the original back**
— otherwise five tier runs would leave five probes' worth of text on the user's
clipboard, and the break above shows exactly whose data that would be.

What makes it pass:

  * `gpui-binding/src/view.rs` — a `Clipboard` value (`Empty`, `Text`, `Other`) read
    once per frame in `begin_frame`, where there is a valid `&App`; a binding function
    has none. That is the same reason the pointer's position and the default colours
    are cached there.
  * `gpui-binding/src/app.rs` and `store.rs` — `Request::SetClipboard`, applied in
    `process_requests`, which has an `App` to write with. The write therefore lands
    after the frame that asked for it, which is also when every other program sees
    it.
  * `gpui-binding/src/lib.rs` — `gpui::clipboard_text()`, `gpui::clipboard_kind()`
    and `gpui::set_clipboard_text(text)`.

What is claimed and what is not — the row says "text and image", and only the text
half round-trips:

  * **Reading** an image is a *kind*: `"image"` means the item is there and none of
    its entries is text, which is what a screenshot or a copied picture looks like.
    That is checkable and is checked.
  * **Writing** an image needs `gpui::ClipboardItem::new_image(&Image)`, and an
    `Image` has to be decoded before it can be handed over. Nothing in this crate
    constructs one — that is the asset pipeline, which the register carries as
    **DW7**. The probe therefore does not pretend to test an image.
