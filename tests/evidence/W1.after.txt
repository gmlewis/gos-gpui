What makes it pass:

  * `gpui-binding/src/window.rs` (new) — a window id is a plain `i64` handed out
    by `allocate()` (the first window is 1, and 0 means "no window"), read back
    with `current()`, and installed around a scope with `with(id, ..)`.
  * `gpui-binding/src/app.rs` — `Root` carries the id of the window it is the
    view of; `run_app` allocates the first one before it opens, `process_requests`
    allocates one for each window a frame asks for, and `Root::render` runs the
    whole frame — the view callback, the translation into elements, and the
    requests the frame raised — inside `window::with(win, ..)`.
  * `gpui-binding/src/lib.rs` — `gpui::window_id()`.

The probe asserts rather than narrates: it stores its id under `w1.seen` on
frame 1 and fails the moment a later frame reads back anything else, so
stability is checked in-program rather than by reading the transcript; and the
second window it opens prints the id it sees, which is 2 and not 1.

One defect found on the way, and it belonged to no capability: the release tier
did not compile at all. `Styled::debug()` is `#[cfg(debug_assertions)]` upstream
(`gpui-0.2.2/src/styled.rs:755`), so `style.rs`'s `"debug" => el.debug()` was
`error[E0599]: no method named debug found for type parameter T` under
`gos build --release`. The token now keeps that gate. See the round log.
