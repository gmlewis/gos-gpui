--------------------------------------------------------------------------------
What the green is evidence of, and what it is not
--------------------------------------------------------------------------------
* **`enter` splitting the line and `up` moving the caret are the widget's, and the
  check tells that apart from upstream's shape.** The break is the one that cannot be
  faked: `"a\n"` is a different document from `"a"`, and the run with `single_line` set
  proves the probe notices.
* **The probe cannot run upstream.** Upstream's window is a Rust example this machine
  does not build, so "upstream binds nothing for `enter`" is a reading of
  `input.rs:680-694`, not a measurement — the same footing every other `invisible` row
  in the census stands on.
* **The probe is the widget's, not the example's.** `ui::editor` is
  `gpui::editor(key, placeholder, style).into()` (`examples/ui/mod.gos:184-186`), so a
  probe can call the same widget `examples/09_input.gos` draws without importing `ui` —
  this probe has no soft joint, unlike `dt1`/`dt2`/`mp3`. What it does *not* exercise is
  the example's own tree; that is `./scripts/regress.sh` and the five tiers over
  `examples/09_input.gos`:
